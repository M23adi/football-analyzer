# Project Overview: Tactical Football Match Analyzer
**Language/Environment:** Python 3.11/3.12, Windows 11, NVIDIA RTX 3050 (CUDA enabled).
**Goal:** Build a modular computer vision pipeline to extract player coordinates from broadcast football footage, separate teams via jersey color, apply a homography matrix, and visualize tactics on a 2D minimap.

## Current Architecture & Completed Modules
The project follows strict modular engineering principles. 
- `main.py`: The execution loop handling video I/O with OpenCV and orchestrating the modules.
- `src/detection.py`: Runs `yolov8m.pt` on the GPU with ByteTrack (`persist=True`) to detect players (class 0) and the ball (class 32). Overrides default plotting to draw custom bounding boxes.
- `src/ball_tracker.py`: A memory module that estimates the ball's position during missed frames due to motion blur.
- `src/team_assigner.py`: Crops the top half of player bounding boxes and uses K-Means clustering (`scikit-learn`) to determine the dominant jersey color, returning RGB values for custom box rendering.

## Immediate Next Task
We are currently building `src/camera_transformation.py`. 
- **Requirement:** Implement a homography matrix using `cv2.findHomography` and `cv2.perspectiveTransform`. 
- **Input:** 4 pixel coordinates from the broadcast video (corners of a penalty box) and 4 corresponding real-world coordinates on a 2D top-down pitch.
- **Output:** A function that takes a player's (x, y) camera coordinates and returns their (x', y') coordinates on the flat 2D tactical map.
